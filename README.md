## 💡 Key Highlights

- **⚡ Custom PyTorch Deep Learning Backbone:** Sub-30ms CPU inference powered by MobileNetV3-Large pre-trained and fine-tuned on plant pathology.
- **🔥 Explainable AI (Grad-CAM Heatmaps):** Visualizes neural network attention directly on infected leaf lesions, proving visual evidence to agronomists.
- **💰 100% Free & Self-Hosted:** Zero third-party API dependencies ($0/month recurring cost).
- **🌿 Dual-Action Remedies:** Step-by-step **Organic bio-remedies (Desi Totkay)** + verified **Pakistani chemical brands** (*Nativo, Score, Ridomil Gold, Movento, Aliette*).
- **⚖️ Pakistani Land Unit Dosage Calculator:** Converts field size in **Acres (ایکڑ)**, **Kanals (کنال)**, and **Marlas (مرلہ)** into exact 16L/20L knapsack battery spray tanks.
- **🔊 Urdu/Pashto/Sindhi Voice Readout:** 1-tap Text-to-Speech (TTS) narration for illiterate farmers.
- **🗄️ Field Diary:** Centralized scan records with Grad-CAM heatmap archives.
